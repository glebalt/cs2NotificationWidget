
# CS2 Widget

A lightweight desktop notification widget for Counter-Strike 2.

### Features
- Real-time game state monitoring via CS2 GSI.
- Animated notifications (fade and scale).
- System tray integration.
- Single-instance execution.
- Customizable WPF interface.

### Technologies
- C#
- .NET 10
- WPF / XAML
- CounterStrike2GSI
- Windows Forms NotifyIcon
- Git

### Requirements
- Windows 10/11 x64
- Counter-Strike 2

### Installation
Download the latest version from [Releases](../../releases) and run `WpfApp2.exe`. It will create dekstop shortcut
